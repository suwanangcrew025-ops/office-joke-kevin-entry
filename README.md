Entry for [The Funniest Office Joke, Judged Head to Head](https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c) on make.fun.

The program (`main.py`, program/v1) writes one office joke to
`/output/entry.txt`: the printer that only jams on deadline day is not
broken but unionised — 195 of the 200 allowed characters, one concrete
scene, one specific object, and the turn in the final clause, when the
printer takes a lunch break, files a grievance and prints the speaker's
resignation letter in Comic Sans every Friday. The joke ships in
`joke.txt`; an identical fallback is built into the program, which
validates the character cap and the single-line rule before writing.
